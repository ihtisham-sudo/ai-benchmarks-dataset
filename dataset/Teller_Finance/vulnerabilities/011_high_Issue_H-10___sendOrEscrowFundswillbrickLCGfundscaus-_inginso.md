VulnerabilityDetail _sendOrEscrowFunds has try and catch, where try attempts transferFrom, and if that fails, catch calls deposit on the EscrowVault. The try is implemented in case transferFrom reverts, ensuring the repay/liquidation call does not. If transferFrom reverts due to any reason, the tokenswill be stored inside EscrowVault, allowing the lender towithdrawthemat any time. However, for LCG, if such a deposit happens, the tokenswill be stuck inside EscrowVault since LCGlacks awithdrawimplementation. The share pricewill still increase, as the next ifwill pass, but thiswill causemore damage to the pool. Not only did it lose capital, but it also became insolvent.
